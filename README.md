# Snapphane scoutdistrikt booking

En bokningsapp för Snapphane scoutdistrikt för att genomföra bokningar av kanoter, scoutstuga, lägerområde och vindskydd.

Kan användas både som gäst eller som en inloggad användare genoom konton skapade i appen med Clerk. Admin-konton har tillgång till admin-verktyg för bekräftelse av bokningar och ändringar av information som ska visas för användare.
Bekräftelse via email och sökbara bokningar med bokningsnummer och email samt redigering.

Appen är byggd för Android och Windows.
